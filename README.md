# Retail Store Sales Analysis Dashboard

## Project Overview

This is my first end-to-end Microsoft Power BI project built using retail store sales data. The project focuses on analyzing sales performance, profit trends, customer behavior, and product insights through interactive dashboards and visual reports.

The dashboard helps transform raw retail data into meaningful business insights that can support better decision-making.

---
![Dashboard Image](Madhav%20Store%20dashboard.jpg)

## Objectives

* Analyze overall sales and profit performance
* Identify top-performing products and categories
* Track customer and regional sales trends
* Monitor KPIs using interactive visualizations
* Practice real-world business intelligence workflows

---

## Features

* Interactive sales dashboard
* KPI cards for revenue, profit, and orders
* Region-wise and category-wise analysis
* Monthly sales trend visualization
* Product performance tracking
* Filters and slicers for dynamic reporting
* Data cleaning and transformation using Power Query
* DAX measures for calculations and insights

---

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Excel / CSV Dataset
